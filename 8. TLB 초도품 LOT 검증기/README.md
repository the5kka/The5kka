# TLB

카드에 있는 TLB LOT NO 바코드를 스캔하고, 초도품 사진에서 인식한 각인과 비교하는 현장용 앱입니다.

## 최종 배포본

- APK: `TLB.apk`
- 앱 이름: `TLB`
- 패키지: `com.kcc.tlb.lotverifier`
- 버전: 1.0.0 (versionCode 1)

## LOT 검증

- 영문 A~Z와 숫자로 된 정확히 9자리
- 허용 예: `362109B09`, `S16189007`
- Android 앱에서는 수기입력을 막고 카메라 바코드 스캔만 사용
- 8자리·10자리·공백·특수문자는 다음 단계 진행 차단

## 작업 흐름

1. 카드 TLB LOT NO 카메라 스캔
2. 9자리·영문숫자 검증
3. 초도품 사진 촬영
4. OCR 인식값과 카드 LOT 대조
5. OK 또는 NG 판정
6. 이력 저장 후 현재 LOT 초기화

NG에서는 `다시 찍기` 또는 `NG 확정 · 조장 확인`을 선택합니다. 사진은 판정 후 삭제하고 인식 문자열만 이력에 저장합니다.

## 자동 초기화 설정

- 기본값: 10분
- 선택: 사용 안 함 / 1분 / 5분 / 10분 / 30분
- 촬영·판정 중에는 초기화를 기다립니다.
- 자동 초기화는 현재 LOT만 지우고 작업이력은 유지합니다.

## 작업이력

- 날짜·완료시간·OK/NG
- 카드 LOT NO·사진 OCR 인식값·판정 사유
- 재촬영 횟수·작업 시작시간·소요시간
- 날짜별 묶음·LOT 검색·날짜 검색

초기 작업이력 비밀번호는 `5300`, 비밀번호 변경용 마스터 비밀번호는 `0160`입니다.

## PC 실행

`PC_실행.bat`를 실행합니다. PC에서는 9자리 LOT 입력·검증과 화면 확인을 할 수 있고 사진 OCR은 Android 앱에서 사용합니다.

## 품질 주의사항

- 카드 LOT와 사진 인식값이 일치할 때만 OK
- 인식 불량은 바로 NG 확정하지 않고 다시 찍기로 재확인 가능
- 이력 저장 실패 시 현재 LOT를 삭제하지 않음
- 앱 삭제 또는 앱 데이터 삭제 시 로컬 작업이력이 삭제될 수 있음
