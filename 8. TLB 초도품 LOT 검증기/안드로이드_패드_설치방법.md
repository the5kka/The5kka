# TLB Android 설치방법

1. 태블릿에서 `내 파일 → 다운로드`를 엽니다.
2. `TLB.apk`를 누릅니다.
3. 설치 후 앱 목록에서 초록색 `TLB` 앱을 실행합니다.
4. 카메라 권한은 `앱 사용 중에만 허용`을 선택합니다.
5. 홈 화면에 없으면 앱 목록의 `TLB`를 길게 눌러 `홈 화면에 추가`를 선택합니다.

## 사용 순서

1. `카메라 스캔`으로 카드의 9자리 LOT를 읽습니다.
2. 화면의 LOT가 카드와 같은지 확인합니다.
3. `초도품 촬영 및 대조`를 누릅니다.
4. OK면 확인하여 이력을 저장합니다.
5. NG면 사진 상태를 확인하고 `다시 찍기` 또는 `NG 확정 · 조장 확인`을 선택합니다.

자동 초기화 기본값은 10분이며 `설정`에서 변경할 수 있습니다. 작업이력 초기 비밀번호는 `5300`입니다.
