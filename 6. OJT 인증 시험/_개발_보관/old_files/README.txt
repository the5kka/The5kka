OJT 랜덤 시험지 생성기

1. 바탕화면의 "OJT 시험 문제.xlsm" 파일을 문제은행으로 사용합니다.
2. run_OJT_Exam_Maker.bat 또는 OJT_Exam_Maker.exe를 실행합니다.
3. 공정을 선택하고 공통/객관식/주관식 문항 수와 점수를 입력합니다.
4. 총점이 목표 점수(기본 100점)와 같을 때만 시험지가 생성됩니다.
5. 생성 결과는 시험지, 답안지, 생성정보 시트가 포함된 xlsx 파일입니다.

참고
- 문제은행 시트에 문제가 추가되면 프로그램이 마지막 행까지 자동으로 읽습니다.
- 문제 유형은 공통, 객관식, 주관식 기준입니다.
- 각 유형별 보유 문제 수보다 많이 요청하면 생성이 중단됩니다.
