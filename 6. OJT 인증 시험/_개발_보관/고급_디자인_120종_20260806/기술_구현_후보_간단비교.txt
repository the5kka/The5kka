OJT EXAM MAKER 화면 구현 후보
==============================

1. C# WinForms 유지 + 화면만 고급화
   장점: 현재 기능과 출력 로직을 가장 안전하게 유지할 수 있음
   단점: 아주 현대적인 애니메이션과 반응형 배치는 작업량이 큼
   추천 상황: 현재 V2 기능을 최대한 건드리지 않고 화면만 교체

2. WPF (.NET 8)
   장점: 디자인, 글자 크기, 화면 확대, 문서 미리보기 구성이 좋음
   단점: 화면 부분은 새로 만들고 기존 기능을 연결해야 함
   추천 상황: 품질관리용 고급 화면과 실제 인쇄 미리보기를 중요하게 볼 때

3. WinUI 3
   장점: 최신 Windows 프로그램처럼 보임, 터치 화면에 좋음
   단점: 배포 환경과 Windows 버전 확인이 필요함
   추천 상황: 키오스크형, 외국인용, 큰 버튼 중심 화면

4. Avalonia UI
   장점: Windows 외 환경 확장 가능, 현대적인 화면 구현 가능
   단점: 현재 C# WinForms 기능을 옮기는 검토가 필요함
   추천 상황: 장기적으로 여러 PC 환경을 고려할 때

5. Qt
   장점: 문서 도구, 다중 패널, 정교한 데스크톱 화면에 강함
   단점: 현재 C# 코드와 별도 기술이므로 전체 이전 비용이 큼
   추천 상황: 완전히 새로운 제품으로 다시 만들 때

현재 프로젝트의 가장 안전한 방향:
1차는 C# WinForms 화면 개선 또는 WPF 화면 + 기존 출력 로직 연결입니다.
최종 선택한 디자인 번호를 기준으로 기능 영향 범위를 다시 검토한 뒤 결정합니다.
