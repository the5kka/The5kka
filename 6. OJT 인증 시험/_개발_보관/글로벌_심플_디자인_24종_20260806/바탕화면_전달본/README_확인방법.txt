OJT Exam Maker 글로벌 심플 디자인 24종
========================================

[가장 먼저 열 파일]
00_OJT_글로벌_심플_디자인_24종.html

[보는 순서]
1. 위 HTML 파일을 더블클릭합니다.
2. 먼저 "추천" 버튼을 눌러 8개만 비교합니다.
3. 마음에 드는 화면을 클릭하면 실제 1600×900 크기로 확대됩니다.
4. 전체를 한눈에 보려면 "전체_비교_01.png", "전체_비교_02.png"를 엽니다.

[먼저 볼 디자인]
01 네 개의 시작 문  : 가장 쉽고 빠른 대상 선택
05 글로벌 체크인    : 국제적인 인상과 익숙한 진행 흐름
16 큰 버튼 키오스크 : 현장 터치 조작에 가장 적합
24 설명 없는 3단계  : 대상 → 공정 → 성명만 확인하는 최소 구조

[용도별 추가 추천]
