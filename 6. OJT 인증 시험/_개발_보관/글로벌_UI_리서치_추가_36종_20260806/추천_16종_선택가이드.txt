이번 추가 추천 16종
===================

25. 공공서비스 시작
- 짧은 설명, 확인 항목, 시작 버튼 하나만 보여줍니다.
- 처음 사용하는 사람에게 가장 안전합니다.

27. 의료 체크인
- 시험 목적과 시작 전 준비사항을 친절하게 설명합니다.
- 고객사와 신입 작업자에게 신뢰감을 주기 좋습니다.

29. Fluent Windows 홈
- Windows 업무 프로그램처럼 익숙한 왼쪽 메뉴와 작업 영역입니다.
- 기존 WinForms 프로그램을 현대화할 때 현실적인 후보입니다.

31. Carbon 데이터 작업대
- 공정 목록과 선택한 시험 정보를 동시에 보여줍니다.
- 관리자가 많은 공정을 빠르게 찾을 때 좋습니다.

33. 산업 오퍼레이터 스테이션
- 네 개의 시험 대상을 대형 산업 패널처럼 표시합니다.
- 현장 모니터와 터치 화면에 잘 어울립니다.

35. SAP 업무 타일
- 시험, 최근 기록, 출력, 관리 기능을 업무 타일로 분리합니다.
- 전문 업무 프로그램 느낌이 강합니다.

38. 고대비 쉬운 선택
- 검정, 흰색, 노란색과 큰 글씨를 사용합니다.
- 시력이 좋지 않거나 멀리서 보는 작업자에게 유리합니다.

39. 명찰 스캔 시작
- 사원증을 스캔하면 작업자와 예정 시험을 자동으로 불러옵니다.
- 작업자 이름 오입력을 줄일 수 있습니다.

41. 승차권 발매기형
- 번호가 있는 네 개의 큰 선택 영역을 사용합니다.
- 별도 교육 없이 터치하기 쉽습니다.

45. 여권 심사형
- 작업자 본인 정보와 응시 시험을 한 화면에서 확인합니다.
- 외국인용과 본인 확인 기능을 확장하기 좋습니다.

49. 사원증 태그 시작
- 사원증을 리더기에 태그하는 행동 하나로 시작합니다.
- 현장 배포 시 가장 빠른 흐름입니다.

50. QR 공정 스캔
- 설비나 공정에 붙은 QR을 인식하여 시험을 자동 선택합니다.
- 잘못된 공정 선택을 줄일 수 있습니다.

53. 공정 배치도
- 실제 설비 배치도와 비슷한 위치에서 공정을 고릅니다.
- 공정이 많아질 때 직관적입니다.

54. 품질 Andon
- 문제은행, 작업자, 출력, 총점을 대형 상태판으로 표시합니다.
- 시작 전 이상 여부를 멀리서 확인하기 좋습니다.

57. 전체 종이 미리보기
- A4 시험지를 화면 중앙에 가장 크게 표시합니다.
- 프린트 낭비를 줄이는 목적에 가장 잘 맞습니다.

60. 한 번에 질문 하나
- 한 화면에서 한 가지만 선택합니다.
- 12살 아이도 설명 없이 사용할 수 있는 구조입니다.
