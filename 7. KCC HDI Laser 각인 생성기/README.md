# KCC HDI

KCC HDI 제조지시서 관리번호·LOT NO·수기입력으로 최종 Laser 각인값을 만들고, 초도품 사진 OCR 결과와 대조하는 현장용 앱입니다.

## 최종 배포본

- APK: `KCC_HDI.apk`
- 앱 이름: `KCC HDI`
- 패키지: `com.kcc.hdi.lasergenerator`
- 버전: 2.2.0 (versionCode 10)
- 기존 V1.5는 PC 숨김 복구 폴더에만 보관하며 태블릿에는 설치하지 않습니다.

## 각인값 규칙

- 관리번호: 영문·숫자 정확히 10자리, 8번째 문자는 영문 A~Z
- LOT NO: 영문·숫자 정확히 14자리
- LOT 9~12번째: `0000`, `0108`, `0916`만 허용
- 수기입력: 영문 또는 숫자 1자리
- 최종값: 관리번호 1~7번째 + LOT 9~12번째 + 관리번호 8번째 + 수기입력
- 예: `GHD1807D16 + B7208901091601 + 7 = GHD18070916D7`

## 작업 흐름

1. 관리번호 바코드 카메라 스캔
2. LOT NO 바코드 카메라 스캔
3. 수기 영문/숫자 1자리 입력
4. CODE 128 바코드와 QR 코드 생성
5. 초도품 사진 촬영 및 OCR 대조
6. OK 또는 NG 확인
7. 이력 저장 후 현재 작업 초기화

NG에서는 `다시 찍기` 또는 `NG 확정 · 조장 확인`을 선택할 수 있습니다. 이력 저장에 실패하면 현재 작업을 삭제하지 않습니다.

## 자동 초기화 설정

- 기본값: 10분
- 설정 선택: 사용 안 함 / 1분 / 5분 / 10분 / 30분
- 설정값은 태블릿 내부에 저장됩니다.
- 촬영 또는 판정 중에는 자동 초기화를 기다립니다.
- 자동 초기화는 현재 입력·바코드·QR만 지우며 작업이력은 유지합니다.

## 작업이력

- 날짜·완료시간·OK/NG
- 관리번호·LOT NO·수기입력·생성 각인값
- 사진 OCR 인식값·판정 사유
- 작업 시작시간·소요시간
- 날짜별 묶음, LOT 전체/일부 검색, 날짜 검색

초기 작업이력 비밀번호는 `5300`, 비밀번호 변경용 마스터 비밀번호는 `0160`입니다.

## PC 실행

`PC_실행.bat`를 실행합니다. PC에서는 입력·검증·바코드/QR 화면을 확인할 수 있으며 카메라 OCR은 Android 앱에서 사용합니다.

## 품질 주의사항

- V1.5 복구본과 과거 시험판은 현장 배포 금지
- 앱 삭제 또는 Android 앱 데이터 삭제 시 로컬 작업이력이 삭제될 수 있음
- 사진은 OCR 판정 후 삭제하며 이력에는 인식 문자열만 저장
- 변경 시 기존 각인 조합·허용 LOT·OK/NG 저장 흐름을 유지
