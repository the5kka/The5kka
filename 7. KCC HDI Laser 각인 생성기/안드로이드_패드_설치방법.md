# KCC HDI Android 설치방법

## 설치파일

`KCC_HDI.apk`

## 설치 순서

1. 태블릿의 `내 파일`을 실행합니다.
2. `다운로드` 폴더로 들어갑니다.
3. `KCC_HDI.apk`를 누릅니다.
4. 출처를 알 수 없는 앱 설치 안내가 나오면 `이 출처 허용`을 켭니다.
5. 설치 후 앱 목록에서 `KCC HDI`를 실행합니다.
6. 카메라 권한은 `앱 사용 중에만 허용`을 선택합니다.

홈 화면에 아이콘이 없으면 앱 목록의 `KCC HDI`를 길게 눌러 `홈 화면에 추가`를 선택합니다.

## 사용 순서

1. 관리번호 카메라 스캔
2. LOT NO 카메라 스캔
3. 수기 영문/숫자 1자리 입력
4. 생성된 바코드 또는 QR을 설비에 스캔
5. 초도품 촬영 및 대조
6. OK면 확인, NG면 다시 찍기 또는 조장 확인

## 설정

- 자동 초기화 기본값은 10분입니다.
- `설정`에서 사용 안 함 / 1분 / 5분 / 10분 / 30분을 선택할 수 있습니다.
- 작업이력 비밀번호 초기값: `5300`
- 관리자 비밀번호 변경용 마스터: 별도 관리자 관리

## 주의

- 태블릿에는 `KCC HDI`와 `TLB` 두 앱만 사용합니다.
- `KCC V1.5`, `KCC V2 [시험판]`은 태블릿에 다시 설치하지 않습니다.
- 앱 삭제 또는 앱 데이터 초기화 전에 작업이력 보관 필요 여부를 확인합니다.
