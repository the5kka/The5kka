# KCC HDI Laser 각인 생성기

제조지시서 관리번호, LOT NO 바코드, 수기 1자리를 조합해 설비용 CODE 128 바코드와 QR 코드를 만드는 현장용 앱입니다.

## 최종 보관 APK — 2개만 사용

| 구분 | 파일 | 앱 이름 | 용도 |
|---|---|---|---|
| 기존 안정판 | `KCC_HDI_V1.5_안정판.apk` | KCC V1.5 [안정판] | V2 문제 발생 시 즉시 사용 |
| 새 시험판 | `KCC_HDI_V2_시험판.apk` | KCC V2 [시험판] | 초도품 촬영·OCR 대조 및 진행 이력 |

두 앱은 서로 다른 앱으로 설치되므로 태블릿에 동시에 둘 수 있습니다. V2가 현장에서 충분히 검증될 때까지 V1.5를 삭제하지 않습니다.

## 조합 규칙

`관리번호 앞 7자리 + LOT NO 9~12번째 4자리 + 관리번호 8번째 문자 + 수기 1자리`

예시:

- 관리번호: `GHD1807D16`
- LOT NO: `B7208901091601`
- 수기 입력: `7`
- 결과: `GHD18070916D7`

## 입력 차단 기준

- 관리번호: 정확히 10자리 영문/숫자, 8번째 문자는 반드시 영문 A~Z
- LOT NO: 정확히 14자리 영문/숫자
- LOT NO에서 추출하는 9~12번째 값: `0000`, `0108`, `0916`만 허용
- 수기 입력: 영문 A~Z 또는 숫자 0~9 한 자리
- 잘못된 값이 하나라도 있으면 바코드와 QR을 생성하지 않음

## V2 작업 흐름

1. 관리번호 바코드를 카메라로 스캔합니다.
2. LOT NO 바코드를 카메라로 스캔합니다.
3. 수기값 한 자리를 입력합니다.
4. 최종값과 한 화면의 CODE 128/QR을 확인합니다.
5. 초도품 각인 사진을 촬영합니다.
6. 사진 인식값이 최종값과 같으면 `OK` 팝업이 표시됩니다.
7. 다르면 `NG`가 표시되며, 촬영 각도나 초점 문제일 수 있으므로 `다시 찍기`를 먼저 사용합니다.
8. 실제 각인 불량일 때만 `NG 확정 · 조장 확인`을 누릅니다.
9. OK 또는 NG를 확정한 뒤에만 현재 입력값이 지워지고 진행 이력에 저장됩니다.

사진은 이력에 저장하지 않으며 OCR 처리 후 임시 사진을 삭제합니다. 진행 이력에는 작업 시각, 판정, 관리번호, LOT NO, 수기값, 최종값과 인식 문자열이 저장됩니다.

## PC 확인

`PC_실행.bat`를 더블클릭합니다. PC에서는 조합·검증·바코드/QR 화면과 진행 이력을 확인할 수 있습니다. 카메라 바코드 스캔과 초도품 OCR은 Android 앱에서 최종 확인합니다.

## 현장 적용 전 확인

- 실제 조명, 촬영 거리, 반사, 기울기 조건에서 여러 장 시험
- 설비 스캐너가 화면의 CODE 128과 QR을 정확히 읽는지 교차 확인
- 사진 인식이 애매하면 절대로 임의 OK 처리하지 말고 다시 촬영
- V2 문제가 있으면 앱 목록에서 `KCC V1.5 [안정판]`을 실행
