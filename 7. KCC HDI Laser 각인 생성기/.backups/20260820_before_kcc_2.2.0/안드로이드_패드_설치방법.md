# KCC HDI 앱 2개 설치 방법 — Galaxy Tab A9

## 최종 모습

태블릿 앱 목록에 아래 두 앱이 각각 보여야 합니다.

1. `KCC V1.5 [안정판]` — 기존 방식
2. `KCC V2 [시험판]` — 새 촬영 대조 방식

V2가 잘 안 되면 V1.5 아이콘을 눌러 바로 기존 방식으로 작업할 수 있습니다.

## 1. PC에서 태블릿 Download 폴더로 복사

1. 태블릿 잠금을 풉니다.
2. USB 케이블로 PC와 태블릿을 연결합니다.
3. 태블릿 USB 알림에서 `파일 전송/Android Auto`를 선택합니다.
4. PC 파일 탐색기에서 `내 PC → Galaxy Tab A9 → 내장 저장공간 → Download`로 이동합니다.
5. 아래 두 APK만 복사합니다.
   - `KCC_HDI_V1.5_안정판.apk`
   - `KCC_HDI_V2_시험판.apk`

APK는 사진이나 일반 문서가 아니라 설치 파일입니다. APK를 바탕화면에 끌어 놓는 것이 아니라 `Download` 폴더에 복사한 후 태블릿에서 설치합니다.

## 2. 두 앱 설치

1. 태블릿에서 `내 파일` 앱을 엽니다.
2. `다운로드`를 누릅니다.
3. `KCC_HDI_V1.5_안정판.apk`를 누르고 `설치`를 선택합니다.
4. 처음 한 번 `알 수 없는 앱 설치` 안내가 나오면 `설정`을 누르고 `이 출처 허용`을 켭니다.
5. 뒤로 돌아와 설치를 완료합니다.
6. 같은 방법으로 `KCC_HDI_V2_시험판.apk`도 설치합니다.
7. 두 앱을 각각 한 번 실행하고 카메라 권한은 `앱 사용 중에만 허용`을 선택합니다.

## 3. 홈 화면에 아이콘 두 개 놓기

1. 태블릿 홈 화면에서 아래쪽을 위로 밀어 전체 앱 목록을 엽니다.
2. `KCC V1.5 [안정판]` 아이콘을 1~2초 길게 누릅니다.
3. `홈 화면에 추가`를 누르거나, 누른 채 홈 화면으로 끌어 놓습니다.
4. `KCC V2 [시험판]`도 같은 방법으로 추가합니다.

설치만 하면 아이콘이 자동으로 홈 화면에 생기지 않을 수 있습니다. 이 경우 위 방법으로 직접 추가하면 됩니다.

## 4. V2 사용 순서

1. `KCC V2 [시험판]`을 실행합니다.
2. 관리번호의 `카메라 스캔`을 누르고 관리번호 바코드를 찍습니다.
3. LOT NO의 `카메라 스캔`을 누르고 LOT NO 바코드를 찍습니다.
4. 수기 입력 칸에 영문 또는 숫자 한 자리를 입력합니다.
5. 생성된 최종값, CODE 128과 QR을 확인합니다.
6. 설비 스캐너로 필요한 코드를 읽습니다.
7. 초도품이 나오면 `초도품 촬영 및 대조`를 누르고 각인 글자를 가깝고 반듯하게 찍습니다.
8. `OK`이면 내용을 확인하고 확정합니다.
9. `NG`이면 먼저 `다시 찍기`로 초점과 각도를 바꿔 재촬영합니다.
10. 재촬영해도 실제 각인이 다를 때만 `NG 확정 · 조장 확인`을 누릅니다.
11. 각인값 생성 후 10분 동안 완료하지 않으면 현재 입력값과 바코드/QR만 자동 초기화됩니다.

## 5. 날짜별 작업이력 확인

1. 화면 오른쪽 위의 `진행 현황`을 누릅니다.
2. 최초 비밀번호 `5300`을 입력하고 `확인`을 누릅니다.
3. 날짜별 OK/NG 건수와 관리번호, LOT NO, 수기값, 각인값, 사진 인식값, 판정 사유와 소요시간을 확인합니다.
4. `LOT NO 검색`에 전체 또는 일부 번호를 입력하면 해당 작업만 표시됩니다.
5. `작업 날짜`를 선택하면 해당 날짜의 이력만 표시됩니다.
6. 다시 전체 이력을 보려면 `검색 초기화`를 누릅니다.

작업이력은 10분 자동 초기화로 삭제되지 않습니다. 단, 앱을 삭제하거나 Android 설정에서 앱 데이터를 삭제하면 작업이력이 사라질 수 있습니다.

## 6. 작업이력 비밀번호 변경

1. 작업이력 비밀번호 화면 또는 날짜별 작업이력 화면에서 `비밀번호 변경/설정`을 누릅니다.
2. 관리자 마스터 비밀번호를 입력합니다.
3. 새 작업이력 비밀번호를 숫자 4~12자리로 입력합니다.
4. 새 비밀번호를 한 번 더 입력하고 `변경 저장`을 누릅니다.
5. 이후부터 `진행 현황`에는 새 비밀번호를 사용합니다.

마스터 비밀번호는 작업이력 조회 비밀번호와 다르며 현장 작업자에게 공유하지 않습니다.

## 7. 촬영 요령

- 렌즈를 깨끗이 닦습니다.
- 각인 문자열 전체가 화면 안에 들어오도록 찍습니다.
- 글자가 너무 작지 않도록 가까이 찍습니다.
- 판넬과 카메라가 최대한 평행하도록 합니다.
- 빛 반사가 글자를 가리지 않게 태블릿 각도를 조금 바꿉니다.
- 다른 숫자나 라벨은 가능하면 사진에서 제외합니다.

## 8. 문제가 생겼을 때

### 카메라 대신 폴더가 열리는 경우

웹 파일이나 APK를 직접 실행한 것이 아니라, 설치된 앱 아이콘을 눌렀는지 확인합니다. 앱을 설치하지 않고 APK 파일을 누르면 `내 파일/다운로드` 화면이 열릴 수 있습니다.

### V2 인식이 계속 NG인 경우

1. 렌즈, 초점, 반사, 기울기를 확인하고 다시 찍습니다.
2. 생성된 최종값과 실제 각인을 눈으로 비교합니다.
3. 실제 각인이 다르면 조장 확인 후 NG를 확정합니다.
4. 촬영 기능 자체에 문제가 있으면 작업을 중지하고 기존 V1.5 앱을 사용합니다.

### 홈 화면에 아이콘이 없는 경우

전체 앱 목록에서 앱 이름을 찾은 후 아이콘을 길게 눌러 `홈 화면에 추가`합니다.

## 9. 삭제하면 안 되는 것

- V2 현장 검증이 끝나기 전에는 기존 V1.5 앱을 삭제하지 않습니다.
- 앱을 삭제하면 해당 앱에 저장된 진행 이력도 사라질 수 있습니다.
- 태블릿 Download 폴더의 APK는 설치용 복사본이며, 실제 실행은 홈 화면/앱 목록의 아이콘으로 합니다.
