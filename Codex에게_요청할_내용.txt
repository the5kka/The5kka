이 폴더에 있는 MES 프로그램을 수정하려고 합니다.

압축을 푼 폴더 위치는 제가 알려줄게요.
예: C:\Users\사용자이름\Desktop\MES_회사수정용

프로그램 설명:
- 이 프로그램은 품질 검사 이력을 등록, 조회, 수정, 삭제하는 Windows용 MES 보조 프로그램입니다.
- 제품명, LOT 번호, 검사일자, 검사자, 검사 결과, 불량 유형, 비고를 입력하고 관리합니다.
- 데이터는 SQLite DB 파일인 quality_history.db 에 저장됩니다.

폴더 구조:
- dev\MES_v1.py : 수정해야 할 원본 파이썬 코드
- data\quality_history.db : 데이터베이스 원본
- exe\MES_v1.exe : 현재 실행파일
- exe\quality_history.db : 실행파일과 같이 사용하는 DB
- exe_다시만들기.bat : 수정 후 EXE를 다시 만드는 배치파일
- python_installer\python-3.14.4-amd64.exe : 파이썬 설치파일

내가 원하는 작업:
1. 먼저 폴더 구조와 dev\MES_v1.py 코드를 확인해줘.
2. 내가 요청하는 수정사항을 dev\MES_v1.py에 반영해줘.
3. 수정 후 가능하면 파이썬으로 실행 테스트를 해줘.
4. 문제가 없으면 exe_다시만들기.bat 을 실행해서 새 MES_v1.exe를 만들어줘.
5. 새 실행파일은 exe\MES_v1.exe 위치에 갱신되게 해줘.
6. exe\MES_v1.exe 와 exe\quality_history.db 가 같이 있어야 실행된다는 점을 유지해줘.
7. 작업이 끝나면 어떤 파일을 수정했는지, 회사에서 어떤 파일을 실행하면 되는지 알려줘.

주의사항:
- quality_history.db 파일은 데이터가 들어 있는 파일이니 함부로 삭제하지 말아줘.
- 기존 데이터가 날아가지 않게 조심해서 작업해줘.
- 내가 말하지 않은 다른 파일은 되도록 건드리지 말아줘.
- 한글이 깨지는 부분이 있으면 UTF-8 인코딩 문제도 같이 확인해줘.
