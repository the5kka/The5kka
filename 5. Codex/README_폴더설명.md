# 5. Codex 폴더 설명

이 폴더는 Codex와 이어서 일하기 위한 기준 자료 보관 폴더입니다.

- `현재 채팅 이어가기.md`: 새 채팅이나 다른 PC에서 이어가기 위한 핵심 인수인계 문서
- `Codex 전달자료`: Codex에게 줄 입력 자료
- `작업결과`: Codex 작업 결과물 보관
- `DNC 업무자료`: DNC 관련 참고/전달 자료
- `실행파일`: 실행 파일 임시 보관

이름 후보:

- `5. Codex_업무기준`
- `5. Codex_인수인계`
- `5. Codex_작업기록`

현재 Codex 프로젝트 연결이 이 폴더를 바라볼 수 있으므로, 폴더명 변경은 프로젝트 연결 상태를 확인한 뒤 진행합니다.
