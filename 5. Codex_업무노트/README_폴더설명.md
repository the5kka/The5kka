# 5. Codex_업무노트 폴더 설명

최종 갱신: 2026-07-10 17:36:13

이 폴더는 Codex와 이어서 일하기 위한 업무 노트/인수인계/작업일지 보관 폴더다.
실제 프로그램 원본, DNC 원본, EXE 운영본을 넣는 곳이 아니다.

## 주요 파일

`	ext
현재 채팅 이어가기.md
프로젝트별 업무노트\
작업일지\
git_auto_save.ps1
~~~

## 운영 방식

- 실시간 자동 저장소가 아니다.
- 중요한 작업이 끝나면 사용자가 마무리 백업해줘라고 말한다.
- Codex는 그때 현재 채팅 이어가기.md, 프로젝트별 업무노트, 작업일지를 갱신한다.
- 파일 변경 백업과 git 저장은 자동화할 수 있지만, 대화 맥락 정리는 Codex가 직접 갱신해야 정확하다.
