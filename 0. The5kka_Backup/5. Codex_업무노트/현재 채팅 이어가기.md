# Codex 현재 채팅 이어가기

최종 갱신: 2026-07-10 17:36:13

## 이 문서의 역할

이 문서는 Codex 앱, PC, 계정, 채팅방이 바뀌어도 작업 맥락을 이어가기 위한 현재 기준 문서다.
대화 내용은 자동 저장되지 않으므로, 중요한 작업이 끝나면 이 문서를 갱신해야 한다.

## 사용자 업무 성격

- 사용자는 PCB 제조업 품질관리/현장 자동화 업무를 수행한다.
- 단순 VBA 사용자가 아니라, Excel/VBA/Python/EXE를 활용해 현장 업무를 단계적으로 시스템화하고 있다.
- 장기 목표는 회사 전용 MES 구축이다.
- 답변/개발은 항상 현장 작업자 기준, 품질관리 관점, 유지보수 가능 구조를 우선한다.

## 중요한 사용자 작업 방식

- 사용자가 질문만 하면 임의 실행하지 않는다.
- 사용자가 해줘, 적용, 바꿔, 진행처럼 명확히 요청하면 실행한다.
- 파일 위치가 애매하면 기본적으로 바탕화면을 우선한다.
- 불필요한 백업 파일을 매번 만들지 않는다. 큰 구조 변경 또는 운영 영향이 큰 작업에서만 백업 여부를 확인한다.
- V1/V2처럼 현장에서 사용 중인 파일은 임의 수정하지 않는다.

## 최근 주요 작업 요약

### 트리밍 작업일보 V3

최근 대화에서는 C:\Users\오국진\Desktop\트리밍 작업일보 V3.xlsm을 중심으로 VBA 알람 기능을 조정했다.

핵심 내용:

- Sheet15 트리밍 작업일보 시트에서 X열 판정값이 NG 또는 관리자 문의일 때 알람.
- Q열 블라인드 처리는 Q8부터 시작하도록 수정했다. Q7은 헤더/필터 줄이므로 가리면 안 된다.
- 451행 이후 삭제 후, 다시 1000행까지 서식/수식을 확장했다.
- 알람 문구 제목은 BGA Trim DNC 조건 이상발생.
- 알람 표시 정보는 아래 형식이다.

~~~text
관리번호 : [G열 값]
LOT NO : [H열 값]

판정값 : 관리자 문의 또는 NG
~~~

주의:

- Application.Interactive = False는 비밀번호 입력칸을 먹통으로 만들어 사용 금지.
- AppActivate Application.Caption도 비밀번호 입력 포커스를 빼앗을 수 있으므로 주의.
- 알람창을 완전히 못 움직이게 하려는 시도는 비밀번호 입력 문제를 만들 수 있다. 현장 적용 전 반드시 직접 테스트해야 한다.

### 공정능력/Minitab 비교

사용자가 S16072A37.xlsx와 Minitab 결과 이미지를 제공했고, 잠재적(군내) 공정 능력 값 차이를 질문했다.
초기 판단은 군내 표준편차(Within Sigma) 계산 방식 차이 가능성이 높다.
실제 파일을 읽고 Minitab의 군내 표준편차 0.0030492와 자체 계산값의 차이를 비교해야 한다.
