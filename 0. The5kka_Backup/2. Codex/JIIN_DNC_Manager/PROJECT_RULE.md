# JIIN DNC Manager Project Rules

## 프로젝트 목적

PCB 제조용 Python 기반 DNC 관리 프로그램이다.

목표:
- 현장 작업 안정성 확보
- 잘못된 DNC 조건 파일 사용 방지
- 작업 이력 DB 저장
- 작업일보 Excel 자동 반영
- DNC 조건 파일 자동 복사/삭제
- Windows EXE 현장 배포 운영

## 절대 변경 금지

아래 항목은 사용자가 명확히 요청하지 않는 한 임의로 변경하지 않는다.

- 기존 DNC 복사 흐름
- 작업일보 저장 컬럼 구조
- LOT 검증 흐름
- 기존 버튼 이름
- 기존 작업 순서
- 기존 DNC 자동 삭제 흐름
- 기존 data 폴더 보존 방식
- 기존 DB 삭제/초기화 금지

## 필수 유지 사항

- Windows EXE 배포 기준
- Python Tkinter 기반 GUI
- 네트워크 공유폴더 사용 가능 구조
- Excel 작업일보 연동 유지
- 현장 작업자 기준 단순 UI 유지
- 작업자 팝업은 짧게 표시
- 상세 원인은 로그에 기록

## 기본 DNC 흐름

```text
LOT 입력
→ 조건/지그 조회
→ 입력값 검증
→ DNC 조건 파일 검색
→ DB 작업 이력 저장
→ DNC 전송 폴더로 조건 파일 복사
→ 일정 시간 후 복사된 파일 자동 삭제
→ 초품/Burr 확인
→ 작업일보 Excel 반영
```

## 공정별 필수 경로

KCC PKG 등 공정별 DNC 진행 시 아래 3가지가 모두 정상이어야 한다.

1. DNC 조건 원본 폴더
2. 작업일보 Excel 파일 경로
3. DNC 조건 전송 폴더

위 3가지 중 하나라도 없거나 접근 불가이면 DNC 진행을 중단한다.

## DNC 조건 파일 검색 규칙

- DNC 작업조건 파일은 `.txt`만 허용한다.
- `.dnc` 파일은 조건 파일로 사용하지 않는다.
- 파일명 완전일치만 허용한다.
- 부분일치 검색 금지
- contains 검색 금지
- startswith 검색 금지
- 한 글자라도 다르면 다른 파일로 판단한다.
- 확장자를 제외한 파일명과 작업조건명이 완전일치해야 한다.

예:

```text
작업조건: KCC_001

허용:
KCC_001.txt

불가:
KCC_001.dnc
KCC_001_REV1.txt
OLD_KCC_001.txt
KCC_001_BACKUP.txt
```

## DNC 조건 파일 검색 결과 처리

### 0개

진행 중단.

메시지:

```text
해당 DNC 파일을 찾을 수 없습니다.
```

### 1개

정상 진행.

### 2개 이상

진행 중단.

메시지:

```text
동일한 DNC 파일이 2개 이상 발견되었습니다.

1. \\DNC\OLD\KCC_001.txt

2. \\DNC\NEW\KCC_001.txt

동일 조건 파일이 2개 입니다. 관리자 확인 바랍니다.
```

## 조건 마스터 규칙

조건 마스터는 작업조건/지그 조회의 기준 데이터다.

조건 마스터 키:

```text
STEP + 차수 + 관리번호 + 공정코드
```

동일 관리번호 조건:

- 동일 관리번호가 조건 마스터에 중복으로 존재하면 안 된다.
- 동일 관리번호 중복 발견 시 "동일 조건"으로 판단하고 관리자 확인이 필요하다.
- 낮은 우선순위 데이터가 높은 우선순위 데이터를 덮어쓰면 안 된다.

조건 마스터 우선순위:

1. 사용자 수정
2. 신규 검증
3. DNC 완료 DB
4. 작업일보 이력

신규 검증으로 확정된 조건은 작업일보 이력으로 덮어쓰면 안 된다.

## 작업일보 반영 규칙

- 작업일보 Excel 파일은 하나를 사용한다.
- 공정별로 Excel 시트를 분리한다.
- Excel 저장 성공 후에만 DB의 exported 값을 반영 완료로 변경한다.
- Excel 저장 실패 시 DB 상태를 변경하지 않는다.
- 미반영 이력은 다음 작업일보 반영 시 다시 반영 가능해야 한다.
- 작업일보 파일이 열려 있거나 경로가 없으면 DB 저장 상태를 유지한다.

## DNC 삭제 규칙

- DNC 실행 전 전송 폴더의 기존 조건 파일 정리는 허용한다.
- 단, 삭제 전/후 로그를 남긴다.
- DNC 실행 후 자동 삭제는 이번 실행에서 복사한 파일을 대상으로 한다.
- 삭제 실패 시 로그를 저장한다.
- DNC 전송 폴더 전체를 무분별하게 삭제하지 않는다.

## 라이선스 규칙

### 마스터 PC

마스터 PC 이름:

```text
KUKJIN
```

- Python에서는 `socket.gethostname()`으로 현재 PC 이름을 확인한다.
- 현재 PC 이름이 `KUKJIN`이면 어떤 네트워크/IP 환경에서도 항상 실행 허용한다.

### 일반 PC

기본 허용 IP 대역:

```text
121.155.196
```

규칙:

- 현재 PC IP를 확인한다.
- 등록된 허용 IP 대역과 `startswith` 방식으로 비교한다.
- 일치하면 실행 허용한다.
- 불일치하면 실행 차단한다.
- 허용 IP 대역이 비어 있으면 모든 PC 실행을 허용한다.

차단 메시지:

```text
라이선스가 불일치 합니다.
관리자에게 문의 바랍니다.
```

- 원본 경로

- 조건 파일 0개/2개 이상 결과

- EXE 빌드일 또는 버전 정보

## 현장 업데이트 규칙

일반 업데이트:

- EXE만 교체
- data 폴더 유지

DB 구조 변경 업데이트:

- EXE 실행 시 자동 마이그레이션
- 마이그레이션 전 data 백업 필수

- 기존 config.json 값 유지

## 작업자 메시지 규칙

작업자 팝업은 짧게 표시한다.

예:

```text
조건 파일 없음
동일 DNC 파일 발견
작업일보 파일 열림
라이선스 불일치
```

상세 원인은 app/error 로그에 기록한다.

## 수정 전 필수 규칙

기능 변경 또는 저장/삭제/검색/라이선스 관련 수정 전 Codex는 반드시 아래 내용을 먼저 검토한다.

1. 영향 파일 분석
2. 수정 계획 설명
3. 변경 대상 파일 설명
4. 기존 기능 유지 여부 설명
5. 테스트 방법 설명

단순 문구/색상/배치 수정은 간단 설명 후 진행 가능하다.

## 테스트 규칙

- 기존 DNC 기능 유지
- 기존 작업일보 정상 반영
- DNC 조건 파일 검색 정상
- DNC 조건 파일 복사 정상
- DNC 조건 파일 삭제 정상
- 조건 파일 0개/2개 이상 차단 정상
- 라이선스 동작 확인
- EXE 빌드 확인
