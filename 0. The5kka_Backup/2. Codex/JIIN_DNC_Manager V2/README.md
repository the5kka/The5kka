# JIIN DNC Manager

Windows Tkinter 기반 KCC PKG DNC 작업 자동화 프로그램입니다.

## 실행 방법

```bat
python main.py
```

필요 라이브러리 설치:

```bat
python -m pip install -r requirements.txt
```

## 작업일보 Excel 선택 방법

1. 프로그램 실행
2. `설정` 탭 클릭
3. `작업일보 Excel 선택` 버튼 클릭
4. 기존 작업일보 Excel 파일 선택
5. `설정 저장` 클릭

선택 경로는 `config.json`에 저장되어 다음 실행 시 자동으로 불러옵니다.

## KCC PKG 일반 DNC 사용 방법

1. `KCC PKG` 탭에서 공통정보와 LOT 1 정보를 입력합니다.
   - 작업일자: 선택 버튼으로 날짜를 고릅니다.
   - 조: A/B/C 버튼으로 선택합니다.
   - 근무: 주간/야간 버튼으로 선택합니다.
   - 작업자: 직접 입력합니다.
2. 2LOT 작업이면 LOT 2 정보도 입력합니다.
3. `작업조건 / 지그 불러오기` 버튼을 눌러 기존 작업일보 이력에서 조건과 지그를 불러옵니다.
4. `일반 DNC 실행` 버튼을 누릅니다.
5. 작업일보 이동 확인, Stack 수, 기종교체 여부를 순서대로 입력합니다.
6. DNC 파일 복사 및 자동 삭제 후 Burr 확인 팝업에 응답합니다.
7. 결과가 작업일보 `KCC PKG` 시트에 누적 저장됩니다.

기종교체가 `예`이면 `자주검사`를 입력해야 DNC가 진행됩니다. 1축 이상 선택하면 되고, `초품 4 Point 확인`과 `지그교체시 하부핀 3개 확인`의 선택 축 개수는 반드시 같아야 합니다. 자주검사 결과는 작업일보 Q:AB 열에 저장됩니다.

작업일보 Excel 파일은 입력 중에는 열어둬도 됩니다. 저장 시점에 파일이 열려 있으면 닫고 다시 시도할 수 있는 안내창이 표시됩니다.

작업조건과 지그는 직접 입력하지 않습니다. 조건 마스터를 먼저 조회하고, 없으면 작업일보 `KCC PKG` 시트 8행 이후 이력을 기준으로 `STEP+차수+관리번호`, `관리번호`, `LOT No` 순서로 찾아옵니다.

공통 입력은 DNC 완료 후에도 지워지지 않습니다.

## 조건 마스터 관리

`조건 마스터 관리` 버튼에서 조건 마스터를 조회하고 수정할 수 있습니다.

`조건 마스터 갱신` 버튼은 작업일보 이력을 읽어 중복을 제거한 뒤 `condition_master.json`에 저장합니다.

조건 마스터 기준:

```text
STEP + 차수 + 관리번호 + 공정코드
```

작업일보에는 공정코드 저장 열이 없으므로, 작업일보에서 전체 갱신한 값은 공정코드가 비어 있을 수 있습니다. 현장에서 조건/지그를 불러오면 현재 입력된 공정코드와 함께 자동 보강 저장됩니다.

## KCC PKG 신규 모델 DNC 사용 방법

1. `KCC PKG` 탭에서 `신규 모델 검증 DNC` 버튼을 누릅니다.
2. 팝업창에서 신규 모델 검증 LOT 정보와 작업조건/지그를 직접 입력합니다.
3. 매수는 선택 입력입니다. 빈칸이면 작업일보에 `더미`로 저장됩니다.
4. 작업일자/조/근무는 KCC PKG 메인 화면의 공통 입력값을 그대로 사용합니다.
5. 실행 시 조장명 입력 팝업이 먼저 표시됩니다.
6. DNC 완료 후 초도품 이상 여부에 따라 K열에 조건명 또는 `[검증 NG 발생] 조건명`이 저장됩니다.

## EXE 만들기 방법

```bat
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name JIIN_DNC_Manager main.py
```

생성 위치:

```text
dist\JIIN_DNC_Manager.exe
```

## 삭제 시간 10초에서 60초로 바꾸는 방법

방법 1: 프로그램 `설정` 탭에서 `DNC 삭제 대기 시간`을 `60`으로 변경 후 저장합니다.

방법 2: `config.json`에서 아래 값을 수정합니다.

```json
"dnc_delete_seconds": 60
```

## 작업일보 Excel 파일 주의사항

작업일보 Excel 파일이 열려 있으면 저장에 실패할 수 있습니다.

저장 실패 메시지가 표시되면 Excel 파일을 닫고 다시 실행해주세요.
