OJT EXAM MAKER 프린트 전용 UI 시험본 4종

[용도]
이 프로그램은 PC에서 시험을 치는 프로그램이 아닙니다.
엑셀 문제은행에서 종이 시험지와 답안지를 만들고 출력하는 프로그램입니다.

[공통 작업 순서]
1. 문제은행 엑셀 파일을 확인하거나 [파일 선택]으로 지정합니다.
2. 일반용, 전장용, 신입용 중 출력 대상을 선택합니다.
3. 공정을 선택하고 성명과 평가 일시를 확인합니다.
4. [시험지 만들기]로 문제를 생성합니다.
5. [출력 미리보기]에서 실제 인쇄 페이지 전체를 확인합니다.
6. [문제 + 답안 프린트]로 문제지 전체와 마지막 답안지 1페이지를 함께 출력합니다.

[4종 차이]
01 네 개의 시작 문: 네 가지 대상을 큰 색상 문으로 선택하는 가장 단순한 화면
04 대화형 안내: 왼쪽 단계 안내를 따라가는 화면
18 스마트 팩토리 맵: 어두운 현장형 화면
31 Carbon 데이터 작업대: 공정 목록과 출력 조건을 한 화면에서 빠르게 확인하는 화면

[중요]
- 네 EXE는 디자인 비교용 시험본입니다. 기존 OJT_Exam_Maker_V2.exe는 변경하지 않았습니다.
- PC 시험, 답안 입력, 제출, 자동 채점 기능은 넣지 않았습니다.
- 외국인용은 추후 문제은행이 추가되면 연결할 예정입니다.
- 관리자 설정 기능과 기존 인쇄 양식은 V2 동작을 유지합니다.
