OJT Exam Maker 글로벌 UI 총 60종

[가장 먼저 열 파일]
00_OJT_글로벌_UI_총60종.html

[구성]
- 이전 디자인: 1~24번
- 이번 추가 디자인: 25~60번
- 총 화면: 60개

[보는 순서]
1. HTML 파일을 더블클릭합니다.
2. 처음에는 "이번 추가 36"만 표시됩니다.
3. 화면을 클릭하면 실제 1600×900 크기로 확대됩니다.
4. "추천 16"을 누르면 이번에 먼저 볼 후보만 남습니다.
5. "전체 60"을 누르면 이전 디자인까지 함께 비교할 수 있습니다.
