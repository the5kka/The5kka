OJT EXAM MAKER 전체 화면 디자인 120종
========================================

1. 가장 먼저 볼 파일
   00_OJT_전체화면_디자인_120종.html

2. 보는 방법
   - 위 HTML 파일을 두 번 클릭하면 인터넷 없이 열립니다.
   - 왼쪽에서 일반용 / 전장용 / 신입용 / 외국인용을 고를 수 있습니다.
   - 추천 24종을 누르면 우선 검토할 화면만 나옵니다.
   - 화면 이미지를 클릭하면 크게 볼 수 있습니다.
   - 확대 화면에서 키보드 왼쪽·오른쪽 화살표로 이동합니다.

3. 빠르게 비교하는 방법
   - 비교표_12개씩 폴더: 12개 화면을 한 장에서 비교
   - 추천_24종 폴더: 우선 추천 화면 24개를 두 장으로 비교
   - 디자인_번호표.csv: 번호, 구조명, 시험 대상을 표로 확인

4. 선택할 때 알려줄 내용
   예) 064번 화면이 좋음
   예) 010번 구조에 033번 색상 느낌을 조합
   예) 104번의 큰 출력 미리보기 + 006번의 대상 선택 방식

5. 중요한 구분
   - 30개 업무 구조를 만들었습니다.
   - 각 구조마다 일반용, 전장용, 신입용, 외국인용 4개 화면이 있습니다.
   - 총 30 × 4 = 120개입니다.
   - 이 폴더는 디자인 검토용이며 실제 EXE가 아닙니다.
   - 현재 OJT_Exam_Maker_V2.exe와 시험지 출력 양식은 수정하지 않았습니다.

6. 추천 24종 선정 기준
   - 대상별 시작 화면
   - 시험지 문서 스튜디오
   - 현장 터치 키오스크
   - 한 문제 집중 화면
   - 다국어 시험 스테이션
   - 종이 우선 미리보기

각 추천 구조를 일반용, 전장용, 신입용, 외국인용으로 각각 만들었습니다.
