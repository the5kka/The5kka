# JIIN DNC Manager

Windows Tkinter 기반 KCC PKG DNC 작업 자동화 프로그램입니다.

## 실행 방법

```bat
python main.py
```

필요 라이브러리 설치:

```bat
python -m pip install -r requirements.txt
```

## 작업일보 Excel 선택 방법

1. 프로그램 실행
2. `설정` 탭 클릭
3. `작업일보 Excel 선택` 버튼 클릭
4. 기존 작업일보 Excel 파일 선택
5. `설정 저장` 클릭

선택 경로는 `data\config.json`에 저장되어 다음 실행 시 자동으로 불러옵니다.

## KCC PKG 일반 DNC 사용 방법

1. `KCC PKG` 탭에서 공통정보와 LOT 1 정보를 입력합니다.
   - 작업일자: 선택 버튼으로 날짜를 고릅니다.
   - 조: A/B/C 버튼으로 선택합니다.
   - 근무: 주간/야간 버튼으로 선택합니다.
   - 작업자: 직접 입력합니다.
2. 2LOT 작업이면 LOT 2 정보도 입력합니다.
3. `조건 / 지그 조회` 버튼을 눌러 조건 마스터에서 조건과 지그를 불러옵니다.
4. `일반 DNC 실행` 버튼을 누릅니다.
5. 기종교체 여부와 Stack 수를 순서대로 입력합니다.
6. 기종교체가 `예`이면 DNC 가동 전에 하부 Pin 3개 확인을 입력합니다.
7. DNC 파일 복사 및 자동 삭제 후 초품 4Point 확인과 Burr 확인 팝업에 응답합니다.
8. 결과는 먼저 DB에 저장되고, `작업일보 반영` 버튼을 누르면 작업일보 `KCC PKG` 시트에 누적 저장됩니다.

기종교체가 `예`이면 `자주검사`를 입력해야 DNC가 진행됩니다. 1축 이상 선택하면 되고, `초품 4 Point 확인`과 `지그교체시 하부핀 3개 확인`의 선택 축 개수는 반드시 같아야 합니다. 자주검사 결과는 작업일보 Q:AB 열에 저장됩니다.

작업일보 Excel 파일은 입력 중에는 열어둬도 됩니다. 저장 시점에 파일이 열려 있으면 닫고 다시 시도할 수 있는 안내창이 표시됩니다.

일반 DNC의 작업조건과 지그는 직접 입력하지 않습니다. `조건 / 지그 조회` 버튼으로 조건 마스터에서 불러옵니다.

공통 입력은 DNC 완료 후에도 지워지지 않습니다.

## 조건 마스터 관리

`조건 마스터 관리` 버튼에서 조건 마스터를 조회하고 수정할 수 있습니다.

`조건 마스터 갱신` 버튼은 작업일보 이력을 읽어 중복을 제거한 뒤 `data\KCC_PKG\condition_master.db`에 저장합니다.

조건 마스터 기준:

```text
STEP + 차수 + 공정코드 + 관리번호
```

작업일보 AC열에는 조건 마스터 복구용 공정코드가 저장됩니다.

## KCC PKG 신규 모델 DNC 사용 방법

1. `KCC PKG` 탭에서 `신규 모델 검증 DNC` 버튼을 누릅니다.
2. 메인 화면에 입력된 STEP/차수/관리번호/LOT No/공정코드는 팝업에 자동으로 들어갑니다.
3. 팝업창에서 신규 모델 검증 작업조건/지그를 직접 입력합니다.
4. 매수는 숫자로 입력합니다. `0`이면 작업일보에 `더미`로 저장됩니다.
5. 작업일자/조/근무는 KCC PKG 메인 화면의 공통 입력값을 그대로 사용합니다.
6. 실행 시 조장명 입력 팝업이 먼저 표시됩니다.
7. DNC 완료 후 초도품 이상 여부에 따라 K열에 조건명 또는 `[검증 NG 발생] 조건명`이 저장됩니다.

## EXE 만들기 방법

```bat
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name JIIN_DNC_Manager main.py
```

생성 위치:

```text
dist\JIIN_DNC_Manager.exe
```

## 현장 배포 / 업데이트 원칙

처음 현장 배포는 `JIIN_DNC_Manager.exe` 하나만 전달해도 됩니다. 현장 조건과 이력은 실행 후 자동 생성되는 `data` 폴더에 저장됩니다.

업데이트 원칙:

```text
일반 업데이트 = JIIN_DNC_Manager.exe만 교체
data 폴더는 그대로 유지

DB 구조 변경 업데이트 = JIIN_DNC_Manager.exe만 교체
새 EXE가 실행되면서 data를 자동 변환
기존 data는 삭제하지 않음
```

현장에서는 `data` 폴더를 삭제하거나 덮어쓰지 않습니다.

## 삭제 시간 10초에서 60초로 바꾸는 방법

방법 1: 프로그램 `설정` 탭에서 `DNC 삭제 대기 시간`을 `60`으로 변경 후 저장합니다.

방법 2: `data\config.json`에서 아래 값을 수정합니다.

```json
"dnc_delete_seconds": 60
```

## 작업일보 Excel 파일 주의사항

작업일보 Excel 파일이 열려 있으면 저장에 실패할 수 있습니다.

저장 실패 메시지가 표시되면 Excel 파일을 닫고 다시 실행해주세요.
