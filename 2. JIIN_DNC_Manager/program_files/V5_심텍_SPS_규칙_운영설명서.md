# JIIN DNC Manager V5 - 심텍 SPS 규칙 운영설명서

작성 기준일: 2026-08-07  
대상 버전: `JIIN_DNC_Manager_V5`  
보호 대상: V1, V2, V3, V4 기존 실행파일과 기존 4개 공정 기능

## 1. 최종 동작 모습

심텍 SPS 화면에서 작업자는 다음 값을 입력한다.

- 관리번호
- LOT No
- 시작 STEP
- 현 STEP
- 차수
- 매수
- OMS 조건1
- OMS 조건2
- 작업자와 공통 근무정보

프로그램은 입력값을 검사한 뒤 다음 중 하나만 표시한다.

1. `조건 조회 OK / 마스터 확정`: 사람이 검증해 등록한 활성 마스터가 정확히 1개인 경우
2. `조건 마스터 없음 / 신규 검증 필요`: 추천은 보여주지만 일반 DNC는 차단
3. `조건 마스터 중복 / DNC 차단`: 같은 조건의 활성 마스터가 2개 이상인 경우
4. `조건 조회 NG`: 입력 누락, STEP 오류, SIZE 미추출 등 기본 검증 실패

규칙 Excel이 추천한 Program은 참고값이다. 추천만으로 일반 DNC를 실행하지 않는다.

## 2. V4 보호와 V5 추가 범위

V4의 TLB, 심텍 HDI, KCC PKG, KCC HDI 흐름은 수정하지 않는다. V5는 V4를 별도 파일로 복사한 뒤 아래만 추가한다.

- 마지막 메뉴 `심텍 SPS`
- 별도 모듈 `simtek_sps.py`
- 별도 규칙 모듈 `simtek_sps_rules.py`
- 별도 DB 영역 `data_v4/SIMTEK_SPS/sps.db`
- 별도 기본 규칙 파일 `data_v5/sps_rules_default.xlsx`

V5가 `data_v4`를 사용하는 이유는 기존 V4 설정과 DB를 이어받아 현장 전환 시 다시 입력하지 않게 하기 위해서다. 심텍 SPS 데이터는 기존 DB 테이블과 섞지 않고 `SIMTEK_SPS` 하위 DB에 저장한다.

## 3. 조건 비교 KEY

### 3.1 일반 DNC의 확정 마스터 KEY

다음 6개가 모두 같아야 같은 확정 조건으로 본다.

`관리번호 정규화 + 차수 + 시작 STEP + 현 STEP + OMS1 정규화 + OMS2 정규화`

Program은 위 조건에 연결된 결과값이다. 활성 마스터가 정확히 1개여야 한다.

### 3.2 관리번호 정규화

관리번호는 비교할 때 영문을 대문자로 바꾸고 공백과 하이픈을 제거한다.

- `FLC10340B00-007`
- `FLC-10340B00-007`
- `FLC 10340B00 007`

위 값은 관리번호 비교에서 같은 값으로 본다. 원문은 DB에 그대로 남긴다.

### 3.3 OMS 정규화

같은 의미의 표시 차이만 정리한다.

- 앞뒤 공백과 연속 공백 정리
- 전각 콜론과 쉼표 정리
- `▷`, `▶`, `►` 같은 표시용 글머리 기호 제외
- 숫자 사이의 `X`, `×`, `*`를 SIZE 구분자 `x`로 정리
- 영문 대소문자 차이 정리

다음 값은 삭제하거나 합치지 않는다.

- SIZE 숫자
- 차수
- CENTER
- 방향홀
- 우측 10mm
- X/Y SHIFT와 부호
- 좌측/우측 Edge R
- Stacking
- 뽕따기 금지
- 그 밖의 OMS 원문

원문과 정규화값을 모두 DB에 저장한다. 추출기가 모르는 새 문구가 생겨도 원문 비교가 남기 때문에 조용히 다른 조건으로 합쳐지지 않는다.

## 4. OMS 조건별 처리

### 4.1 OMS 조건1

OMS 조건1에서 SIZE를 찾는다. 현재 지원 예시는 다음과 같다.

- `Size 411 512 mm` -> `411-512`
- `CUT SIZE : 415X516mm` -> `415-516`
- `후가공 413-513 mm` -> `413-513`

SIZE를 찾지 못하면 추천과 DNC를 모두 차단한다.

### 4.2 OMS 조건2

OMS 조건2 원문을 저장하고 다음 항목을 별도로 추출한다.

- `PIN_POSITION`: CENTER 여부
- `DIRECTION_HOLE`: 방향홀 여부
- `RIGHT_10MM`: 우측 10mm 여부
- `PROCESS_PASS`: 후가공 1차, 2차 등
- `PUNCH_PROHIBIT`: 뽕따기 금지 여부
- `SIZE_NOTE`: SIZE 주의/확인 문구
- `STACKING`: 스텍/STACKING 여부
- `SHIFT_X`, `SHIFT_Y`: 부호와 소수 포함
- `LEFT_EDGE_R`, `RIGHT_EDGE_R`: 좌우 Edge R

OMS2의 어느 한 항목이라도 원문이 다르면 확정 마스터 일반 DNC에서는 다른 조건으로 본다.

## 5. STEP 규칙

현재 V5 허용 기준은 다음과 같다.

`현 STEP = 시작 STEP +60 또는 +70`

예:

- 시작 180 / 현 240 -> OK (+60)
- 시작 180 / 현 250 -> OK (+70)
- 시작 180 / 현 230 -> NG (+50)

이 기준은 제공된 `2026 ST-PKG 1호기 작업일보 V15.xlsm`의 VBA 실행 로직에서 확인한 +60/+70을 적용한 것이다. 제공 자료에는 +50/+60 흔적도 있었으나 실제 V15 VBA 실행 경로에서 +50 허용을 확인하지 못했다. 현장에서 +50이 정상 사례로 확인되기 전에는 품질 사고 방지를 위해 차단한다.

규칙을 바꿀 때는 `simtek_sps_rules.py`의 `ALLOWED_STEP_DELTAS`만 변경하고, +50, +60, +70 각각을 실제 LOT로 재검증한다.

## 6. 추천 Program 우선순위

신규 조건 검증 화면의 추천 순서는 다음과 같다.

1. 관리번호 전용 규칙
2. 과거 동일 관리번호 + 동일 STEP + 동일 OMS1 + 동일 OMS2의 정상 완료 이력
3. 제품군 + 차수 + SIZE + OMS2 상세 규칙
4. 제품군 + 차수 + SIZE + `ANY` 일반 규칙
5. 관리자 확인

과거 이력은 초품 4Point와 4면 Burr가 모두 `이상 없음`인 완료 기록만 사용한다.

후보가 2개 이상이면 사용횟수가 많아도 자동 선택하지 않는다. 화면에 후보를 보여주고 조장 확인을 거쳐 신규 검증을 진행한다.

## 8. 신규 조건 검증 흐름

1. 일반 화면 입력
2. 시작/현 STEP과 OMS1/OMS2 검증
3. 동일 LOT와 2LOT 조건 불일치 차단
4. 신규 조건 검증 창 열기
5. 과거 정상 이력 및 규칙 추천 표시
6. 최종 Program 직접 확인
7. 실제 조건 폴더에서 같은 이름의 `.txt` 검색
8. 0개면 차단, 2개 이상이면 차단, 정확히 1개만 허용
9. 조장명 팝업 입력
10. DNC 파일 복사
11. 초품 4Point 확인
12. 제품 4면 Burr 확인
13. 두 확인이 모두 이상 없을 때만 활성 마스터 등록
14. DB 로그 저장

초품 또는 Burr가 NG이면 실행 이력은 남지만 조건 마스터에는 등록하지 않는다.

## 9. 일반 DNC 흐름

1. 조건 조회 버튼 클릭
2. 활성 마스터 1개 확인
3. LOT 1/2 사용 시 동일 LOT 여부 확인
4. LOT 1/2의 STEP, 차수, OMS1, OMS2 일치 확인
5. 두 LOT의 확정 Program 일치 확인
6. 실제 `.txt` 파일 정확히 1개 확인
7. DNC 전송 폴더에 복사
8. 설정된 시간 뒤 복사 파일 자동 삭제
9. 초품 4Point와 4면 Burr 확인
10. DB 완료/NG 기록

## 10. 자동 차단 항목

- 필수 입력 누락
- 시작 STEP 또는 현 STEP 숫자 오류
- STEP 차이가 +60/+70이 아님
- OMS 조건1 SIZE 미추출
- LOT 1과 LOT 2의 LOT No 동일
- 2LOT STEP, 차수, OMS1, OMS2 불일치
- 일반 DNC에서 조건 조회 미완료
- 활성 마스터 0개 또는 2개 이상
- 2LOT Program 불일치
- 조건 폴더 없음
- 전송 폴더 없음
- Program `.txt` 0개 또는 2개 이상
- 다른 DNC 실행 중
- 신규 검증 대상에 이미 활성 마스터 존재
- 조장명 미입력

## 11. DB 저장 구조

### 11.1 `sps_condition_master`

확정된 조건만 저장한다.

- 관리번호 원문/비교 KEY
- 시작 STEP/현 STEP/차수
- OMS1/OMS2 원문과 정규화값
- SIZE와 OMS2 요약 KEY
- OMS2 추출 상세 JSON
- 최종 Program
- 조장명, 등록 근거, 등록일
- 활성/제외 상태와 제외 사유

잘못 등록한 마스터는 삭제하지 않고 `마스터 제외`로 비활성화한다. 같은 조건은 이후 다시 신규 검증해 새 활성 마스터로 등록할 수 있다.

### 11.2 `sps_dnc_logs`

모든 실행과 NG 이력을 저장한다.

- 작업일시, 설비, 조, 근무, 작업자
- 관리번호, LOT, 시작/현 STEP, 차수, 매수
- OMS1/OMS2 원문·정규화값과 추출 상세
- Program, DNC 구분, 조장명, 추천 근거
- 원본 파일과 전송 파일 경로
- 초품/Burr 결과, 완료/실패 원인
- 작업일보 반영 여부

## 12. 작업일보 연결 계획

심텍 SPS 작업일보는 사용자가 현재 V4 공용 작업일보에 새 시트를 만든 뒤 연결한다. 새 시트의 실제 이름, 헤더 행, 첫 데이터 행, 열 순서와 수식을 확인하기 전에는 임의로 최종 매핑하지 않는다.

현재 참조 V15에서 확인한 후보 매핑은 다음과 같다.

- STEP, 관리번호, LOT, 수량, 실적, 차수
- OMS 조건1, OMS 조건2, 작업 P/G
- 자주검사, Trimming 확인, 작업 시작시간
- 중복 반영 방지용 `DNC_LOG_ID`

새 시트 연결 전에도 DNC 결과는 SPS DB에 `미반영`으로 남는다. 나중에 연결 후 미반영 이력을 순서대로 작업일보에 반영할 수 있다. 작업일보 저장이 성공한 뒤에만 DB의 반영 상태를 완료로 바꾼다.

## 13. 규칙 파일 수정 방법

### 가장 안전한 방법

1. 원본 규칙 파일을 복사해 새 버전으로 저장
2. `MGMT_RULE` 또는 `RULE_MAIN`에 행 추가
3. 설정 화면에서 새 규칙 파일 선택
4. 심텍 SPS 화면의 `추천 규칙 상세` 확인
5. 신규 조건 화면에서 추천만 시험
6. 실제 Program 파일이 정확히 1개인지 확인
7. 현장 승인 후 사용

같은 Key에 Program을 2개 등록하면 자동 선택하지 않고 후보로 표시한다.

## 14. Excel 호환성

- 규칙 파일은 단순 셀 값으로 읽으므로 Excel 2007 이상에서 편집 가능
- 제공 규칙 파일은 XLOOKUP, TEXTAFTER, LET을 사용하지 않음
- Excel 2024 사용 가능
- 작업일보 `.xlsx`와 `.xlsm` 모두 연결 가능하도록 설계
- `.xlsm`은 VBA 보존 방식으로 열되, 최종 공용 작업일보 새 시트 연결 후 실제 파일로 별도 검증 필요

## 15. 아직 현장 확인이 필요한 항목

1. STEP +50이 실제 정상인지 여부
2. OMS2에서 현재 추출 목록에 없는 신규 표현
3. 규칙 파일에 없는 제품군/SIZE/차수
4. 최종 공용 작업일보의 새 시트명과 열 위치
5. 실제 SPS 조건 폴더와 전송 폴더 권한
6. DNC 삭제 대기시간
7. 설비에서 Program 수신 후 실제 가공 결과

위 항목은 추측으로 자동 허용하지 않는다. 확인 전에는 차단 또는 관리자 확인 상태로 남긴다.
