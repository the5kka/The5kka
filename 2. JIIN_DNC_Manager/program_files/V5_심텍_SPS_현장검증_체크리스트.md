# V5 심텍 SPS 현장검증 체크리스트

대상: `JIIN_DNC_Manager_V5.exe`  
목적: 잘못된 Program 전송, 조건 누락, 중복 저장을 현장 배포 전에 차단

## A. 기존 V4 보호 확인

- [ ] TLB 탭이 V4와 동일하게 열림
- [ ] 심텍 HDI 탭이 V4와 동일하게 열림
- [ ] KCC PKG 탭이 V4와 동일하게 열림
- [ ] KCC HDI 탭이 V4와 동일하게 열림
- [ ] 기존 설정과 기존 DB가 보임
- [ ] V4와 V5가 동시에 실행되지 않음

## B. 심텍 SPS 설정

- [ ] 심텍 SPS 조건 폴더를 선택함
- [ ] DNC 전송 폴더가 실제 설비 전송 위치임
- [ ] SPS 추천 규칙 파일을 선택함
- [ ] 작업일보는 새 시트를 만든 뒤 실제 공용 파일로 연결함
- [ ] 경로가 없을 때 임의 폴더가 만들어지지 않고 DNC가 차단됨

## C. 입력과 STEP

- [ ] 시작 180 / 현 240은 +60으로 OK
- [ ] 시작 180 / 현 250은 +70으로 OK
- [ ] 시작 180 / 현 230은 +50으로 차단
- [ ] OMS 조건1이 비면 차단
- [ ] OMS 조건2가 비면 차단
- [ ] OMS 조건1에서 SIZE를 못 찾으면 차단
- [ ] 매수 0은 더미로 저장됨

## D. OMS 조건 비교

- [ ] `▷`와 공백 차이만 있는 OMS는 같은 조건으로 조회됨
- [ ] SIZE 숫자가 다르면 다른 조건으로 차단됨
- [ ] X SHIFT 부호가 다르면 다른 조건으로 차단됨
- [ ] Y SHIFT가 다르면 다른 조건으로 차단됨
- [ ] CENTER/방향홀/우측10mm 차이가 있으면 다른 조건으로 차단됨
- [ ] 좌우 Edge R이 다르면 다른 조건으로 차단됨
- [ ] Stacking/뽕따기 금지 문구 차이가 있으면 다른 조건으로 차단됨

## E. 2LOT 방지 시험

- [ ] LOT 1과 LOT 2가 같은 LOT No이면 일반 DNC 차단
- [ ] 같은 LOT No이면 신규 검증도 차단
- [ ] STEP이 다르면 차단
- [ ] 차수가 다르면 차단
- [ ] OMS 조건1이 다르면 차단
- [ ] OMS 조건2가 다르면 차단
- [ ] 확정 Program이 다르면 일반 DNC 차단

## F. Program 파일 시험

- [ ] 정확한 Program `.txt` 0개이면 차단
- [ ] 정확한 Program `.txt` 1개이면 다음 단계 허용
- [ ] 같은 이름의 `.txt` 2개 이상이면 경로를 표시하고 차단
- [ ] 비슷한 이름이나 다른 확장자는 선택하지 않음
- [ ] 전송 후 설정 시간 뒤 복사 파일만 삭제됨
- [ ] 원본 조건 파일은 삭제되지 않음

## G. 신규 조건 검증

- [ ] 추천 근거와 후보 Program이 표시됨
- [ ] 후보 2개인 경우 자동으로 하나를 확정하지 않음
- [ ] 최종 Program을 직접 확인할 수 있음
- [ ] 조장명 팝업이 뜨고 빈 이름은 진행되지 않음
- [ ] 초품 4Point 확인 팝업이 뜸
- [ ] 제품 4면 Burr 확인 팝업이 뜸
- [ ] 두 항목 모두 이상 없음일 때만 마스터 등록
- [ ] 한 항목이라도 NG이면 마스터 미등록, 실행 이력은 저장

## H. 마스터 관리

- [ ] 정상 신규 검증 조건이 일반 조회에서 1개만 검색됨
- [ ] 마스터 제외 후 일반 조회에서 사용되지 않음
- [ ] 제외한 동일 조건을 다시 신규 검증해 재등록 가능
- [ ] 활성 마스터를 인위적으로 2개 만든 시험 DB에서는 DNC가 차단됨
- [ ] 마스터 이력 Excel 내보내기가 가능함

## I. DB와 작업일보

- [ ] DNC 실행 전 DB 로그가 생성됨
- [ ] 초품/Burr 결과가 DB에 기록됨
- [ ] 실패 원인이 DB에 기록됨
- [ ] 작업일보 연결 전에는 DB 미반영 이력으로 남음
- [ ] 새 작업일보 시트 연결 후 OMS 조건1/2와 Program이 각각 저장됨
- [ ] 작업 시작시간은 날짜 없이 시간만 표시됨
- [ ] 같은 DNC_LOG_ID가 두 번 반영되지 않음
- [ ] 작업일보 저장 실패 시 DB 반영 완료로 바뀌지 않음
- [ ] 큰 작업일보 저장 중에도 V5 화면 입력이 멈추지 않음

## J. 네트워크와 오류 복구

- [ ] 조건 폴더 네트워크가 끊기면 DNC 차단
- [ ] 전송 폴더 네트워크가 끊기면 DNC 차단
- [ ] 작업일보가 열려 있거나 잠겨 있으면 DB 미반영 유지
- [ ] 프로그램 재실행 후 미반영 이력을 다시 반영 가능
- [ ] 숨은 팝업 때문에 메인 화면이 영구 정지하지 않음
