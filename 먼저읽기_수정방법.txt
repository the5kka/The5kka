MES 수정용 파일 설명서

이 압축파일은 회사 PC에서 MES 프로그램을 직접 수정하고 다시 실행파일(EXE)로 만들 수 있도록 준비한 개발용 패키지입니다.


0. 이 프로그램은 무엇인가요?

이 프로그램은 품질 검사 이력을 등록하고 관리하는 Windows용 간단 MES 보조 프로그램입니다.

주요 용도:

- 제품명, LOT 번호, 검사일자, 검사자 정보를 기록합니다.
- 검사 결과를 합격/불합격으로 저장합니다.
- 불량 유형과 비고를 함께 남길 수 있습니다.
- 저장된 검사 이력을 표 형태로 조회합니다.
- 기존 이력을 선택해서 수정하거나 삭제할 수 있습니다.

쉽게 말하면 엑셀 대신 품질 검사 이력을 입력, 조회, 수정, 삭제하기 위한 작은 관리 프로그램입니다.


0-1. 프로그램을 그냥 실행만 하는 방법

회사 PC에서 수정 없이 사용만 할 경우에는 파이썬 설치가 필요 없습니다.

실행 방법:

1) 압축을 풉니다.
2) exe 폴더를 엽니다.
3) MES_v1.exe 를 실행합니다.

주의:

- exe 폴더 안의 quality_history.db 파일을 지우지 마세요.
- MES_v1.exe 와 quality_history.db 는 같은 폴더에 있어야 합니다.
- quality_history.db 에 입력한 검사 이력 데이터가 저장됩니다.


0-2. 회사 PC에서 수정까지 하려면?

회사 PC에서 화면 문구, 입력 항목, 기능 등을 수정하려면 파이썬 설치가 필요합니다.

수정할 파일:

dev\MES_v1.py

수정 후 다시 실행파일을 만들 때 사용할 파일:

exe_다시만들기.bat


1. 압축 풀기

먼저 ZIP 파일을 바탕화면 같은 찾기 쉬운 곳에 압축 해제하세요.

압축을 풀면 폴더 구조가 아래처럼 보입니다.

MES_회사수정용
  data
  dev
  exe
  final
  python_installer
  먼저읽기_수정방법.txt
  exe_다시만들기.bat


2. 폴더 설명

data
- 데이터베이스 원본 보관 폴더입니다.
- quality_history.db 파일이 들어 있습니다.

dev
- 실제로 수정할 원본 코드 폴더입니다.
- MES_v1.py 파일을 수정하면 됩니다.

exe
- 회사에서 바로 실행할 실행파일 폴더입니다.
- MES_v1.exe 를 실행하면 프로그램이 켜집니다.
- quality_history.db 는 MES_v1.exe 와 같은 폴더에 있어야 합니다.
- 이 DB 파일을 지우면 기존 데이터가 사라지거나 새 DB가 만들어질 수 있으니 주의하세요.

final
- 최종 배포본을 따로 보관하고 싶을 때 쓰는 빈 폴더입니다.

python_installer
- 파이썬 설치파일이 들어 있습니다.
- 인터넷 다운로드 없이 이 파일로 파이썬을 설치할 수 있습니다.


3. 회사 PC에 파이썬 설치하기

회사 PC에서 프로그램을 "실행만" 할 거면 파이썬이 필요 없습니다.
하지만 회사 PC에서 MES_v1.py 를 수정하고 다시 EXE를 만들려면 파이썬이 필요합니다.

설치 순서:

1) python_installer 폴더를 엽니다.
2) python-3.14.4-amd64.exe 를 실행합니다.
3) 설치 첫 화면에서 반드시 아래 항목을 체크합니다.

   Add python.exe to PATH

4) Install Now 를 눌러 설치합니다.
5) 설치가 끝나면 PowerShell 또는 명령 프롬프트를 새로 엽니다.
6) 아래 명령어를 입력해서 설치 확인을 합니다.

   python --version

버전이 표시되면 설치가 된 것입니다.


4. MES 소스 수정하기

수정할 파일:

dev\MES_v1.py

간단한 문구 수정은 메모장으로도 가능하지만, 가능하면 Visual Studio Code 같은 편집기를 쓰는 것이 좋습니다.

수정 후 저장하세요.


5. 수정한 프로그램 테스트하기

PowerShell을 열고 압축 푼 폴더로 이동합니다.

예시로 바탕화면에 압축을 풀었다면:

cd "$env:USERPROFILE\Desktop\MES_회사수정용\dev"

그 다음 실행합니다.

python MES_v1.py

프로그램 창이 뜨면 수정 내용이 잘 반영됐는지 확인하세요.


6. 수정한 내용을 EXE로 다시 만들기

압축을 푼 MES_회사수정용 폴더 안에 있는 아래 파일을 더블클릭하세요.

exe_다시만들기.bat

이 파일이 하는 일:

1) pyinstaller 설치
2) dev\MES_v1.py 를 exe로 변환
3) 새로 만든 MES_v1.exe 를 exe 폴더에 복사
4) quality_history.db 도 exe 폴더에 유지

완료되면 아래 파일이 최신 실행파일입니다.

exe\MES_v1.exe


7. 회사에서 다시 배포할 때

다른 사람에게 보낼 때는 최소한 아래 2개 파일이 같은 폴더에 있어야 합니다.

exe\MES_v1.exe
exe\quality_history.db

둘 중 하나라도 빠지면 제대로 실행되지 않거나 데이터가 비어 보일 수 있습니다.


8. 자주 생기는 문제

문제: python 명령어가 안 먹힘
해결:
- 파이썬 설치할 때 Add python.exe to PATH 체크를 안 했을 가능성이 큽니다.
- 파이썬을 다시 설치하면서 Add python.exe to PATH 를 체크하세요.
- 설치 후 PowerShell을 새로 열어야 합니다.

문제: pyinstaller 설치가 안 됨
해결:
- 회사 PC 인터넷이 막혀 있을 수 있습니다.
- 이 경우 인터넷 가능한 PC에서 다시 EXE를 만들어서 전달하는 방식이 더 쉽습니다.

문제: 프로그램은 켜지는데 데이터가 안 보임
해결:
- MES_v1.exe 와 quality_history.db 가 같은 폴더에 있는지 확인하세요.
- exe 폴더 안의 quality_history.db 를 지우지 마세요.

문제: 보안 경고가 뜸
해결:
- 개인 제작 EXE라서 Windows에서 경고가 뜰 수 있습니다.
- 신뢰 가능한 파일이면 "추가 정보" 후 "실행"을 누르면 됩니다.


9. 핵심 요약

수정은 dev\MES_v1.py
실행은 exe\MES_v1.exe
DB는 exe\quality_history.db
다시 EXE 만들기는 exe_다시만들기.bat
